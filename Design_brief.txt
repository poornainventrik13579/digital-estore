1. Users Table : Stores customer information.
CREATE TABLE Users (
tenant_id int(10) UNSIGNED NOT NULL COMMENT 'Tenant ID',
user_id BIGINT(15) NOT NULL,
username VARCHAR(50) NOT NULL UNIQUE,
first_name VARCHAR(50),
last_name VARCHAR(50),
image VARCHAR(256) NOT NULL UNIQUE,
phone VARCHAR(100) NOT NULL UNIQUE,
email VARCHAR(100) NOT NULL UNIQUE,
user_type ENUM('INDIVIDUAL', 'COMPANY') NOT NULL DEFAULT 'INDIVIDUAL',
company_name VARCHAR(100), -- Only applicable for COMPANY users
company_registration_number VARCHAR(50), -- Only applicable for COMPANY
users
company_address1 VARCHAR(255), -- Only applicable for COMPANY users
company_address2 VARCHAR(255), -- Only applicable for COMPANY users
company_country VARCHAR(255), -- Only applicable for COMPANY users
company_pincode VARCHAR(255), -- Only applicable for COMPANY users
tax_id VARCHAR(50), -- Only applicable for COMPANY users
otp VARCHAR(8) NOT NULL UNIQUE,
password_hash VARCHAR(255) NOT NULL,
status VARCHAR(2) NOT NULL, -- -1 INACTIVE, 0 ACTIVE
created_by VARCHAR(2) NOT NULL,
created TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
updated_by VARCHAR(2) NOT NULL,
updated TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
PRIMARY KEY (tenant_id,user_id)
);
CREATE TABLE Currencies (
tenant_id int(10) UNSIGNED NOT NULL COMMENT 'Tenant ID',

currency_name VARCHAR(50) NOT NULL,
is_default VARCHAR(1) NOT NULL
exchange_rate decimal(10,4) NOT NULL,
symbol VARCHAR(10) NOT NULL,
status VARCHAR(2) NOT NULL, -- -1 INACTIVE, 0 ACTIVE
created_by VARCHAR(2) NOT NULL,
created TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
updated_by VARCHAR(2) NOT NULL,
updated TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,

PRIMARY KEY (tenant_id,currency_code)
);

Currencies Table:
A new table that holds supported currencies. Both the Products table (via
default_currency) and Orders table (via currency_code) reference this table.

The ProductPrices table allows you to define the price of each product in one or

The ProductTranslations and CategoryTranslations tables store localeâ specific

that the system can present the correct text based on the user's locale.
Orders & Payments:
The Orders table now stores a currency_code to capture the currency used for
that order. The Payments table remains largely unchanged, assuming payments
align with the order currency.
